# Third-party source material

This directory contains source material that must accompany redistributed
components whose license requires source availability.

- `certifi-2026.7.22-installed-source.zip` contains the exact Python source and
  certificate data bundled from the installed certifi 2026.7.22 distribution.

FFmpeg is not distributed in this repository or release executable. Its fixed
upstream binary and corresponding source URLs are documented in
`../THIRD_PARTY_NOTICES.md` and are also written next to the binary if the
application downloads it at runtime.
